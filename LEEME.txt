ADRIANO YTDOWNLOADER

USAR DESDE USB
1. Copia esta carpeta completa al USB.
2. En la otra computadora, copia la carpeta al Escritorio o Documentos.
3. Abre Adriano YTDownloader.exe.

INSTALAR EN EL EQUIPO
Abre la aplicacion y pulsa "Instalar en este equipo". Copia el programa
a tu usuario y crea un acceso directo en el Escritorio. Despues puedes
cerrar la ventana del USB y abrir el acceso directo sin conectar el USB.
No necesita permisos de administrador. No copia tus descargas ni historial.

DESCARGAR
Pega uno o varios enlaces (uno por linea). Elige formato y carpeta y pulsa
Descargar. Puedes agregar otros enlaces mientras siguen las descargas.
Se inicia con MP4 | Maxima calidad y 3 tareas simultaneas (ajustable 1-8).
En Descargas selecciona una tarea para cancelarla. Limpiar historial borra
los registros; no elimina videos. No se descargan subtitulos.

CARPETA COMPLETA
Solo hay una aplicacion que debes abrir: Adriano YTDownloader.exe.
tools contiene los motores internos; no tienes que ejecutarlos.
Conserva el archivo .exe.config y las carpetas tools y Licencias.
No necesitas instalar Python, FFmpeg ni JavaScript por separado.
Se necesita Internet para descargar y comprobar actualizaciones.

PORTABILIDAD
Las preferencias e historial se crean en Datos. Los videos se guardan
inicialmente en Descargas dentro de esta carpeta. Las rutas dentro del
paquete se guardan relativas para soportar cambios de letra del USB.
Si eliges una carpeta externa, esa ruta solo servira donde exista.
No uses varias ventanas compartiendo la misma carpeta de datos.

COMPATIBILIDAD
Windows 10/11 x64: motor oficial de yt-dlp y Deno.
Windows 7/8 y Windows de 32 bits: motor comunitario de nicolaasjan,
QuickJS de Bellard y FFmpeg x86. Windows 7 debe tener SP1 y los parches
de sistema necesarios; un equipo sin actualizar puede necesitar UCRT
y certificados actualizados. No se ha comprobado en Windows 7 real.
La interfaz puede usar .NET 4.x (Windows moderno) o .NET 2.0/3.5
(incluido en Windows 7); el archivo .exe.config selecciona el disponible.
No se garantiza compatibilidad con ARM ni con instalaciones recortadas.

ACTUALIZACIONES
Al abrir se comprueba el motor oficial. Si no hay conexion se muestra
que no pudo verificarse. El motor compatible se conserva sin sustituirlo
por la version oficial, que no funciona en Windows 7.
